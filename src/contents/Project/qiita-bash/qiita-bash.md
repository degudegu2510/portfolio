## プロジェクト概要

**Qiita Bash** は、Qiita ユーザー向けに定期開催しているトークイベントです。開催回ごとにテーマを設け、登壇者を公募する LT（ライトニングトーク）とネットワーキングを通じて、技術の知見を共有します。

イベントの企画、集客、運営、配信までを一人で担当しています。

### 補足情報

* 期間：2024年4月〜
* 担当：企画 / 集客 / 運営 / 配信（一人で担当）
* 開催形式：オフライン（のちにオンライン配信を加えたハイブリッド開催）
* 使用ツール：connpass / OBS / YouTube
* [Qiita Bash 定期開催のお知らせ（プレスリリース）](https://corp.qiita.com/releases/2024/10/qiita-bash/)
* [【Qiita Bash】ハイブリットイベントを開催するための配信環境](https://qiita.com/degudegu2510/items/509b818b4dff52d03c30)
* [Qiita Bash | AI時代のボトルネック、みんなはどう乗り越えてる？（connpass）](https://increments.connpass.com/event/395196/)


## 背景・課題

Qiita のイベントはこれまでオンラインのものが中心で、ユーザーが集まるオフラインのコミュニティイベントの実績はあまりありませんでした。

一方で、AI の登場により、エンジニアのアウトプットは記事を書くことだけでなく、**登壇したい** というニーズにも広がっています。しかし、コロナ禍の影響もあり、気軽に登壇できる場所は少なくなっていました。

そこで、**登壇したいエンジニアなら誰でも応募できる、公募型の LT イベント** をつくることにしました。

## 進め方

1. 開催回ごとのテーマ設定と、会場を提供してくれる協賛企業との調整
2. connpass でのイベント公開と、登壇者の公募
3. 集客（connpass の通知、Qiita のメール、自身の X、協賛企業からの告知）
4. 当日の運営と配信
5. アンケートでの振り返りと、次回への改善

## デザイン上の判断とその理由

### 登壇者を公募する形にした

登壇の場が少なくなっている中で、「登壇してみたい」エンジニアの受け皿になることを目指しました。登壇経験は問わず、初めての登壇も歓迎する形にしています。

### オフライン開催から始め、オンライン配信を加えた

Qiita としてオフラインのコミュニティをつくることを優先し、まずはオフラインで開催しました。その後、会場に来られない人も楽しめるように、YouTube でのオンライン配信を加えたハイブリッド開催にしています。

### 最小限のコストで運営できる配信環境にした

配信は Qiita として初めての取り組みだったため、機材の選定から OBS の設定まで自分で調整しました。会場の既存機材を活かし、少ない機材で配信できる構成にすることで、継続して開催できるコストに抑えています。

## 成果

* 毎回、参加者満足度 10点中8点以上を維持している。
* 回によっては、オンラインを含めて500〜600名が集まるイベントになった。
* 毎回、登壇者に困ることなく運営できている。
* 最小限のコストで継続的に開催できる運営体制をつくれた。
